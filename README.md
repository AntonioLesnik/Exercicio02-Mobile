# Pedra, Papel e Tesoura

Projeto Android em Java desenvolvido com base no projeto prático da disciplina de Mobile.

## Funcionalidades
- Escolha entre Pedra, Papel e Tesoura.
- O aplicativo sorteia uma jogada usando `Random`.
- A jogada do aplicativo é definida com `switch`.
- O resultado é decidido com `if/else`.
- Comparações de `String` feitas com `.equals()`.
- Placar de vitórias, derrotas e empates.

## Como abrir
1. Abra o projeto no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Execute em um emulador ou celular Android.
